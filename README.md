# 오송포장팀 일일실적보고

휴대폰 링크로 일일 포장 실적을 입력하는 화면입니다. 일자 · Shift · 라인 · 작업 구성(생산1 · 청소 · 세팅 · 생산2) · 품목 · 제조번호 · 작업자를 고르고 실적량만 입력하면, 일정 달성률을 자동으로 계산해 「오송포장팀 실적집계표」 구글 시트에 저장합니다.

- 일정 달성률 = 고른 작업마다 같은 가중치(1 ÷ 작업 수). 생산 = 실적 ÷ 목표 × 가중치, 청소 · 세팅 = 완료 시 가중치 전부
- 포장계획 · 작업자 명단은 구글 시트에서 읽습니다(시트를 고치면 링크에 바로 반영). 작업자 명단은 팀 PIN이 맞을 때만 내려받습니다
- `config.js` : 시트의 Apps Script 웹 앱 주소
